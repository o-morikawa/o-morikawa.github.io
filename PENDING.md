# Pending / source-dependent items

1. **September 2026 slide filenames.** The bundled ResearchMap export predates the September 2026 JPS updates, so several September records have no `dataset_name` from which to derive an exact GitHub slide URL. The database does not guess those filenames. The author-supplied correction remains canonical: `presentation-2026-09-16-gradient-flow-actions-integerness-and-gluonic-fermionic-topo` is dated **2026-09-16**. Because the literal TeX entry gives the meeting range Sep 14--17, 2026, the importer preserves that as `latex_start_date` / `latex_end_date` without overwriting the explicit correction.

2. **TQFT 2025 date disagreement.** `presentation.tex` gives 2025-09-03 for “Non-perturbative analysis of resonance physics by exact WKB method,” while ResearchMap gives 2025-09-05 and names the slide `tqft250905.pdf`. The database preserves the CV/LaTeX date as `start_date`, the ResearchMap value as `researchmap_date`, and marks `date_conflict: true` instead of choosing silently.

3. **TeX-only provisional preprint.** `sources/publication.tex` contains “A physical connection criterion for reaction-coordinate reduction in quantum-field tunneling,” while the bundled `ref_om.bib` has no corresponding INSPIRE BibTeX key. v0.1.1 therefore keeps it immediately as a local provisional publication record. When a matching INSPIRE BibTeX entry is later added, the BibTeX merge promotes the record to that key and retains the local ID in `legacy_ids`.
