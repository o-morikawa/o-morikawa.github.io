# Black-Hole Response Theory — Revised Draft

Authors: Okuto Morikawa, Shoya Ogawa, Takuya Hirose

English translation: ChatGPT (GPT-5.6 Sol, OpenAI)

## Scope

This is the English edition of the revised draft monograph. It is written for senior undergraduate readers and connects causal response of classical fields, resonance spectra, quantum linear response, horizon thermality, the eigenstate thermalization hypothesis (ETH), and response invariants through a single organizing object: the retarded Green function.

## Typesetting

The English edition no longer depends on pLaTeX/upLaTeX, `jsbook`, `dvipdfmx`, `pxjahyper`, `pbibtex`, or `mendex`. The default build uses pdfLaTeX, BibTeX, and MakeIndex. The main file is `main.tex`.

```sh
pdflatex main.tex
bibtex main
makeindex main.idx
pdflatex main.tex
pdflatex main.tex
```

Normally, run the following command at the project root:

```sh
make
```

The document loads `imakeidx` with the `noautomatic` option. Terms marked by `\term{...}` are printed in the text and written to `main.idx`; the English index is generated by `makeindex`.

A standard TeX Live installation with `book`, `geometry`, `CJKutf8`, `tcolorbox`, `imakeidx`, and related packages is required. The local files `omphys.sty`, `natbib.sty`, and `utphys.bst` are retained.

## Japanese quotations

Japanese/CJK quotations retained from the source are typeset locally with:

```tex
\usepackage{CJKutf8}
\newcommand{\jp}[1]{\begin{CJK*}{UTF8}{ipxm}#1\end{CJK*}}
```

No Japanese typesetting engine is required for the rest of the manuscript.

## Project structure

- `main.tex`: main file
- `chapters/`: chapters and appendix
- `ref.bib`: bibliography database
- `omphys.sty`: mathematical and physics notation
- `natbib.sty`, `utphys.bst`: bibliography formatting
- `Makefile`: pdfLaTeX/BibTeX/MakeIndex build recipe

## Index

Technical terms to be indexed are marked in the text with `\term{...}`. For example:

```tex
\term{quasinormal mode}
```

The editorial principle of this revised edition is a “physics minimum”: the main text retains only material needed for the physical line of argument, while prospective extensions are moved to a small number of research problems.
